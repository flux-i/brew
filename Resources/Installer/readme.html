Before you install

Quit any running copy of Brew before installation. After installation, open Brew from Applications and look for the coffee cup in your menu bar.

Using Brew

Left click opens the controls. Right click toggles the awake session. Option-click always opens the controls. The default global keyboard shortcut is Option-Command-B.

About this release

The installer is unsigned, and the app is locally signed rather than Developer ID signed. This release is not notarized by Apple. macOS may ask you to approve opening it in System Settings > Privacy & Security.

AppleScript and URL automation are included. Native Shortcuts actions require a separate Xcode build with App Intents metadata.

Closed-lid protection depends on macOS, hardware, and power conditions.
