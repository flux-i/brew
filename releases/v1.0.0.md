The first Brew release: a native macOS menu bar app that keeps your Mac awake for calls, downloads, presentations, and focused work.

### Downloads

- **Brew-1.0.0-arm64.pkg** — Installer for Apple Silicon Macs; places Brew in `/Applications/Brew.app`.
- **Brew-1.0.0-arm64.zip** — Direct app download; unzip and drag Brew into Applications.
- **Brew-1.0.0-arm64-SHA256SUMS.txt** — SHA-256 checksums for both downloads.

Requires macOS 13 or later on Apple Silicon. Tested on macOS 27. Intel Macs are not supported by these release binaries.

### Install and run

Quit any running copy of Brew, install the package, and open Brew from Applications. The app appears as a coffee cup in the menu bar and has no Dock icon. Left click opens the controls; right click toggles the awake session. The default global shortcut is **Option-Command-B**.

**Signing:** This installer is unsigned. The app has a local ad-hoc signature and is **not Developer ID signed or notarized**. macOS Gatekeeper may block downloaded files. If you choose to install this release, use the approval option in **System Settings → Privacy & Security → Open Anyway** after attempting to open the download. See [Apple's instructions for opening unidentified or unnotarized software](https://support.apple.com/en-us/102445).

### Included

- Indefinite sessions; 15/30/45-minute and 1/4/8/12-hour timers; custom durations and end times.
- Countdown and progress display, saved duration, and an optional menu bar countdown.
- System and display sleep prevention, optional display sleep, and deactivation on charger disconnect.
- Launch at login, activation on launch, optional completion notifications, and notification sound.
- Configurable click behavior, recorded global hotkeys, and light/dark/system appearance.
- A coffee icon with correct dark-mode contrast; closing the popup or Settings keeps Brew running.
- AppleScript and URL automation, plus automatic assertion cleanup and independent OS timeouts.

Native Shortcuts metadata is not included in this standalone build; use the Shortcuts **Open URLs** action with `brew://start`, `brew://stop`, or `brew://toggle`. Closed-lid behavior depends on hardware and macOS policy. The interface is English.

### Validation

17 core tests (58 assertions) passed. The PKG and ZIP contain identical app files, code-signature integrity checks pass, and native Installer selects the correct Applications payload on this Mac. Live diagnostics from the extracted app verify power assertions, independent timeout, cleanup, charger transitions, saved preferences, and global hotkey registration. SHA-256 checksums are included. The package contains the app and installer documentation, with no install scripts or changes to system power settings.
